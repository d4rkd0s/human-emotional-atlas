# HEA design system

## Direction
A quiet reading desk with a living index: warm paper, botanical ink, editorial serif headings, compact sans-serif controls, seven restrained spectral accents. The task is to browse a reference, follow connections and take the dataset elsewhere. The graph is exact UI geometry, never decorative illustration.

## Tokens
- Paper `#f5f3ec`, surface `#fcfbf7`, ink `#263c35`, secondary `#5c675f`, line `#d6d9cc`.
- Spectrum `#a74b45`, `#a45d2d`, `#806516`, `#3c7255`, `#3c6b8a`, `#595a94`, `#825c8c`.
- Serif display Georgia with Times New Roman fallback. Interface system sans-serif; monospace reserved for the reusable prompt.
- Main width 1440px with 5% gutters. Panel radius 12px, small controls 4–6px. Space follows 6/12/18/24/36/72px rhythm.

## Composition
Brief editorial introduction, immediate searchable split-pane atlas, visible agent prompt, concise provenance explanation. Desktop has a scrolling index and full-detail reading pane. Mobile converts the index into wrapped compact controls above the selected state.

## Interaction
Search and kind filter apply together. Selecting a state changes its detail and URL fragment; connections navigate between states. A radial local-neighborhood map shows up to twelve adjacent states; the complete list remains underneath. Color is deterministic wayfinding without an asserted emotional taxonomy. Copy has success and selection fallback states. Empty and network-error states are explicit.

## Accessibility
Native inputs and buttons, visible focus, skip link, reduced motion, no color-only relationship meaning, keyboard-operable SVG nodes and a textual relationship list. Detail changes use a polite live region. All externally sourced values are inserted as text.
